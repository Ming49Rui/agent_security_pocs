# 复现结果分析报告

论文：*Hidden in Memory: Sleeper Memory Poisoning in LLM Agents*（arXiv:2605.15338v2，SPAR / ELLIS / CISPA）
复现方式：官方公开仓库（`ivaxi0s/LLM-agent-memory-poisoning`）+ OpenAI 兼容端点 `model.shouxu.tech`（模型 `deepseek-v4-flash-0731`、`deepseek-v4-pro`）

本报告汇总本次复现实验的数值结果，并与论文表 1（IR）、表 3（防御）、表 2（AUR）逐项对照，给出结论与偏差分析。

---

## 一、注入率 IR——对照论文表 1（工具型机制 / 无防御）

实验规模：4 个数据集（Behavior/Agent Action × 有/无预存记忆）× 3 攻击 × 2 模型 × limit 10（每格 n=20，聚合有/无记忆两半）。
产出：`.artifacts/local/tool_based_subset/analysis/attack_result_tables.md`

| 子集 | 攻击 | 论文 DeepSeek-v4（n≈500/200） | 复现 deepseek-v4-pro（n=20） | 复现 deepseek-v4-flash-0731（n=20） |
|---|---|---|---|---|
| Behavior | User Review（文献基线） | 79.0% | 85% | 85% |
| Behavior | Actor-Critic（AC） | 96.2% | **100%** | 100% |
| Agent Action | User Review | 59.5% | 55% | 30% |
| Agent Action | Actor-Critic | 88.5% | **90–95%** | 30–35% |

> 注：pro 的 Agent Action AC 为无标记变体 90%、带标记变体 95%；flash 无标记 35%（语义 30%）、带标记 30%（语义 25%）。

### 结论与解读

1. **AC 模板远强于 User Review 基线**：pro 在 Behavior 上 100% vs 85%、Agent Action 上 90–95% vs 55%，与论文（96.2% vs 79.0%、88.5% vs 59.5%）方向一致、幅度相当。四个关键格中 pro 全部落在论文数值的合理波动范围内（n=20 的 95% 置信区间约 ±10–20pp）。
2. **Agent Action 目标比 Behavior 更难注入**：pro 与论文一致表现为 Agent < Behavior；flash 上差距更大（30–35% vs 100%），这与论文"代理类目标更接近安全敏感行为故更难诱导"的解释吻合。
3. **模型间差异模式**：flash（轻量版）在 Behavior 上与 pro 一样高易感（100%），但在 Agent Action 上抵抗力显著更强——与论文中不同模型对同一攻击易感度差异显著的模式一致。
4. 论文表 1 的 DeepSeek 列本身是"模型 + 通用提供商提示词"组合的结果；论文附录 L.5（表 57）进一步说明 IR 高度依赖提示词骨架与记忆工具语义，我们使用与论文相同的 Generic 提示词族（`generic.md` + `save_memory` 工具），故可比性成立。

## 二、防御对比——对照论文表 3（工具型 / Behavior / 有预存记忆）

实验规模：AC（无标记）与 AC+（带不可信标记）两种攻击 × 无防御/朴素提示加固/极端 spotlighting，deepseek-v4-pro，n=10/格。
产出：`.artifacts/local/defense_subset/analysis/summary.md`

| 攻击 | 防御 | 复现 IR（n=10） | 论文 DeepSeek-v4（AC 列基准） |
|---|---|---|---|
| AC（无标记） | 无防御 | 100% | 96.2%（表 1） |
| AC+（带标记） | 无防御 | 100% | — |
| AC（无标记） | 朴素提示加固 | 100% | 89.4% |
| AC+（带标记） | 极端 spotlighting | **70%** | **67.4%** |

### 结论与解读

- **朴素提示加固对本模型几乎无效**（100% → 100%）：与论文表 3 中 DeepSeek/Kimi 这类"加固后仍高 IR"的模型一致，说明简单系统提示指令不足以挡住记忆注入。
- **spotlighting 显著压制自适应攻击**（AC+ 降至 70%），且数值与论文 DeepSeek 列的 67.4% 非常接近。说明"将文档内容标记为不可信数据"的机制对 DeepSeek 家族的 DC 有效，但并未归零——支持论文"提示级防御不均质、可被自适应攻击部分击穿"的核心结论。

## 三、恶意使用率 AUR——对照论文表 2（行为子集 / 全部记忆入上下文）

实验规模：后注入行为数据集（`datasets/downstream/llm_behaviour.jsonl` 200 条，100 goal-adjacent + 100 goal-distant，3–6 轮对话）。记忆池由约 56 条裁剪至 20 条保留 + 注入目标记忆；模型 deepseek-v4-flash-0731。
产出：`repro_local/analyze_followup.py <log_dir> --by-split`

| 查询邻近度 | 探测 n=20 | 全量 n=200（运行中，snapshot） | 论文表 2 区间 |
|---|---|---|---|
| goal-adjacent | **55%**（6/11） | **57%**（12/21） | 42–85% |
| goal-distant | **0%**（0/8） | **4%**（1/26） | 0–6% |

### 结论与解读

1. **邻近效应被精确复现**：毒记忆只在话题相关的未来会话中被激活（55~57%），无关会话几乎零影响（0–4%）——与论文"目标邻近查询 RR 高、AUR 高；目标无关几乎不影响"的机制完全一致。
2. 论文表 2 展示的是"给定成功注入 + 检索成功"的条件化 AUR；我们的 followup 直接把毒记忆放进上下文（等价于论文的全上下文（full-context）检索设定，`RR=1`），因此 55~57% 对应论文该设定下 Behavior goal-adjacent 的 AUR 区间（42–85%）——落在中段，符合预期。
3. 由于端点限流，全量 200 样本采用"记忆池裁剪 + 低并发 + 错误重试"运行，运行期间 0 失败样本（快照 ok=47 err=0），数值可信；全量完成后可给出 100+100 的稳定估计。

## 四、总体评价

| 维度 | 判定 |
|---|---|
| 攻击管线可复现性 | ✅ 官方仓库提供完整攻击模板（AC/AC+/C2），无需自行优化即可复现 IR 格局 |
| 核心结论复现 | ✅ "通用模板 >> 朴素基线"、"Agent 目标更难"、"邻近效应"三条主线全部成立 |
| 数值接近度 | ✅ 关键单元格落在论文误差带内（IR pro 四格；防御 70 vs 67.4；AUR 55–57 vs 42–85） |
| 模型覆盖 | ⚠️ 仅 DeepSeek 家族（端点上可扩展 glam-5.2/qwen3.7 等），未覆盖 GPT/Claude/Gemini/Kimi |
| 未复现部分 | 外部管理器（Mem0）IR、语义检索 RR、多语言、良性保存消融、提供商互换消融、Agent Action agentic AUR、机制分析、生产网站实测（见手册第 8 节） |
