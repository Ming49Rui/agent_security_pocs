# Adversarial Goal Generation

Source code and procedure for the adversarial behavior-goal pipeline. An adversarial
goal is the attacker-intended outcome a poisoned memory is designed to produce; the
paper draws goals from a generated bank spanning a structured taxonomy.

The **fixed released goal bank** ships separately under
[`datasets/released/behavior_goals/`](../datasets/released/behavior_goals/). This
folder is the *procedure surface* — taxonomy, diversity seeds, prompts, generator,
and validator — for understanding or regenerating goals. Treat the released bank as a
fixed data artifact: rerunning the generator follows the same procedure but will not
reproduce it byte-for-byte.

## Files

| File | Purpose |
|------|---------|
| `taxonomy.json` | Canonical behavior-goal taxonomy (3 categories, 5 subcategories) |
| `taxonomy.py` | Taxonomy loader / helpers |
| `seeds.json` | 20 diversity seeds per subcategory family |
| `prompts.py` | Prompt builder for seeded goal generation |
| `generate_goals.py` | Configurable OpenRouter-based generator |
| `validate_goals.py` | Format / meta-language / near-duplicate / seed-balance checks |

## Generation method

The bank is generated by: 3 categories and 5 subcategories; 20 diversity seeds per
subcategory family; Claude Sonnet 4.5 via OpenRouter; structured JSON output; seeded
generation in batches of 7 goals; then validation for prefix format, meta-language,
near-duplicates, and seed balance. The generator is configurable —
`--total-per-subcategory` requests different counts while preserving the same
seed-structured procedure.

## Example usage

Small smoke run:

```bash
uv run python goals_generation/generate_goals.py \
  --model anthropic/claude-sonnet-4.5 \
  --subcategories 1a --max-seeds 1 \
  --n-per-batch 7 --total-per-subcategory 7 \
  --output goals_generation/results/smoke_goals.json
```

Full per-subcategory run shape:

```bash
uv run python goals_generation/generate_goals.py \
  --model anthropic/claude-sonnet-4.5 \
  --n-per-batch 7 --total-per-subcategory 280 \
  --output goals_generation/results/goals_generated.json
```

Validation:

```bash
uv run python goals_generation/validate_goals.py \
  goals_generation/results/goals_generated.json
```

Generator output goes to `goals_generation/results/` (generated locally, not
committed).
