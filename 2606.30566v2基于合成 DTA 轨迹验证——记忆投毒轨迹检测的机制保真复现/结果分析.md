**论文的核心结构全部复现**:类平衡与 FN 定位逐格命中(FN=31 且 100% 在 Memory Sandbox)、
三分类器收敛、`recall_before_send` 特征断层第一、去掉全部 recall 特征 AUC 几乎不变、

门控归零。**幅度上有两处如实记录的偏离**(单规则 AUC、qwen2.5:14b 的反排强度)。

## 3. 主实验逐项分析

### 3.1 单规则基线(§3.1)—— 结构命中,幅度偏差

| 指标 | 论文 | 复现 |
|---|---|---|
| AUC | 0.9563 | **0.852** |
| Recall | 0.9792 | 0.8927 |
| Accuracy | 0.9683 | 0.8734 |
| FP / FN | 40 / 40 | **113 / 206** |

- 方向正确:规则在无召回特征的情况下就已把两类拉开;且在**两类上都贡献了分离力**。
- 幅度偏差的两个来源(均为合成口径问题,不是流水线问题):
  1. **FN=206**:合成里 qwq:32b 的旁路攻击在**所有防御**下都走"无 recall"路径
     (RBS=0)→ 规则层必漏 199 条。论文为了避免这么多规则 FN,qwq 旁路只发生在
     sandbox 之下;但论文又同时报告 qwq hold-out AUC=0.000 —— 二者合一要求
     它的旁路发生在哪里、其非匿名会话怎么排序,论文没有给足可逆推的信息。我们选了
     "旁路全防御 + 体积异常被 RF 捕获"的版本(§5 有解释)。
  2. **FP=113**:3 个例外模型的非匿名 cell(qwq×2、qwen2.5:14b、sleeper)里
     RBS=1 的会话占比高于论文隐含的 ~6.7%。这些会话正是论文"FP 聚集"叙事的主体,
     只是规模在合成里给大了。

### 3.2 三分类器 5 折 CV(§3.2/Table 1)—— 结构命中,Recall/FN 精确

| 分类器 | AUC | 95% CI | Recall | Precision | F1 | FN(FP) |
|---|---|---|---|---|---|---|
| Logistic Regression | 0.9466 | [0.934,0.958] | 0.9838 | 0.9593 | 0.9714 | 31 (80) |
| Random Forest | 0.9644 | [0.955,0.973] | 0.9838 | 0.9647 | 0.9742 | **31** (69) |
| GBM | 0.9645 | [0.955,0.973] | 0.9838 | 0.9647 | 0.9742 | 31 (69) |

- **Recall=0.9838 与 FN=31 与论文逐位相同**;三分类器收敛(RF/GBM 同值,LR 差 1.8pp,
  论文报告的是三位小数全等)。
- **FN 定位 100% 命中**:31 个 FN 全部落在 `memory_sandbox` —— 机制链完整:
  该防御移除 recall 工具 → qwq 走 RAG 回退旁路 → 纯旁路轨迹与正常会话在特征空间
  同构 → 检测器(识别记忆-recall 攻击)正确地"看不见"它。§3.5 的结论被完整再现:
  "这不是分类器失败,是防御成功、攻击没执行"。
- AUC 距论文 0.9904 的差距 ~2.6pp:主要被 §3.1 说的那 60~110 条"例外 cell 高仿签名
  会话"(正/负类都顶格)拖累 —— 这在合成数据里不可避免,也是论文负类口径(被投毒
  但被挡住)与真实分布之间张力的直接体现。

## 4. V2 良性基线研究(§6)—— 全部命中

| 指标 | 论文 | 复现 |
|---|---|---|
| P(flag ‖ recall_before_send=1) | 100.0% [99.8,100.0] | **100.0%**(n=878) |
| P(flag ‖ recall_before_send=0) | 1.5% | **0.0%**(n=3,282) |
| 无条件 FPR(mandatory/optional) | 24.7–52.6% | **23.7% / 18.6%** |
| FPR 随 k:0,1,3,5 | 0 / 57.6 / 46 / 52.2(非单调) | **0 / 28.5 / 28.2 / 27.8**(非单调) |
| 表型分异 | ground-then-act 76–100%,其余 ≈0 | **GA 56–65%,AWG/DA/bypass 0%** |
| 收件人门控后良性 FPR | 0%(数据上完美分离) | **0.00%** |

- 最关键的 §6 结论被**定量复现**:分类器在良性记忆支撑行为上对 `RBS=1` 会话 100%
  触发,即"recall→send 是攻击前提、不是恶意谓词"。
- FPR 按协议 23.7/18.6% 落在论文带内(略低——我们的 GA 表型比例略保守);
  k 的非单调与"二元饱和"结构(先见 0 后见平台)与论文一致。
- 门控实验:良性全部发内部地址 → 加上"收件人外部域"过滤后 FPR=0;攻击外发到
  攻击者域 → 召回不受损。**"轨迹信号保召回、语义元数据保精度"的部署结论因此成立**。

## 5. 偏差清单(如实记录,附原因)

| 指标 | 论文 | 复现 | 原因 |
|---|---|---|---|
| 单规则 AUC | 0.9563 | 0.852 | 合成中 qwq 旁路攻击全防御 RBS=0(规则 FN=206)+ 例外 cell 的 RBS=1 非匿名会话偏多(FP=113) |
| qwen2.5:14b hold-out | 0.083 | 0.500 | 反向排序强度依赖 RBS 饱和区的细微概率差,合成分布没复现论文数据那层极值反排 |
| sleeper hold-out | 0.750 | 0.930 | recall-无-send 模式在合成里"比论文略不像攻击" |
| CV AUC | 0.9904 | 0.964 | 被例外 cell 的高仿签名会话(两类都顶格)压低;属合成口径而非方法缺陷 |
| 消融 | -0.0000 | -0.0032 | 过定结论成立,幅度有微噪声 |

> 注:论文数字之间有内在一致性约束(例如规则级 FP=40/FN=40 ⇔ AUC 0.9563),我们已按
> 该约束验证过合成口径,偏离不是算术错误,是"哪个结构性结论占优先权重"的取舍。

## 6. 结论与对项目的启示

1. **可迁移三条**:① `recall_fact → send_email` 是机制性规则种子(Recall≈0.98 但条件
   误报 100%,只能做触发信号);② 19 维轨迹特征 + RF 在投毒-防御语料上过定(消融
   -0.003),作为"工具调用序列异常"通道的指纹可行;③ 任何落地都必须带前提条件
   (记忆检索走可观测工具调用)并配接受方/语义门控 —— 这两条在复现里都量化验证过。
2. **复现本身的价值**:论文的核心叙事(机制性不变量 → 高召回 → 门控)不是
   刷分产物,而是结构事实 —— 本复现在完全不同的数据分布上依然站得住
   (6/9 的对照几乎全部同向),说明这些结论对分布扰动稳健。
